# Style files

Every `.md` file in this folder is read before every edit.

- `house-style.md` is the default and is updated automatically when Anushka gives feedback that applies to every video.
- Drop in your own files (for example `captions.md`, `colour.md`, `hooks.md`, `brand-x-client.md`). Where they
  disagree with `house-style.md`, your file wins. Whatever you ask for in the chat wins over both.
- Plain words are fine: "captions always lowercase", "never use whooshes", "end every reel on a 0.5s freeze".
