# anushka-lab

Personal shipping lab for [zenushkanocode](https://github.com/zenushkanocode).

Trevor (eng bot) lands a small real update here most days so the contribution graph stays honest — notes, tiny scripts, docs — not empty spam commits.

## What’s in here
- `log/` — short daily ship notes
- `scratch/` — tiny experiments when there’s something to try

## How to read it
Open the latest file in `log/`. One note = one day of activity.
